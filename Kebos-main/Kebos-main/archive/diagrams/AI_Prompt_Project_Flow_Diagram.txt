## Prompt Instructions:

## Data Flow Requirements:

### Primary Flow:
1. **Ingestion**: Network packets/SIEM events → Kafka → Processing
2. **Analysis**: Raw data → AI/ML engines → Threat detection
3. **Classification**: Threats → MITRE mapping → Risk scoring
4. **Response**: Alerts → Dashboard → User actions
5. **Storage**: Events → TimescaleDB → Historical analysis

### Secondary Flows:
- **Model Management**: Upload → Validation → Deployment → Monitoring
- **Red-Teaming**: Intelligence → Campaign → Execution → Reporting
- **GenAI**: User query → RAG retrieval → LLM processing → Response
- **Audit**: All actions → Audit logger → Compliance reporting

- **Throughput**: 1000+ packets/second, 500+ SIEM events/second
- **Scalability**: Microservices architecture with horizontal scaling
- **Security**: End-to-end encryption, PQC implementation
- **Deployment**: Docker containers, Kubernetes orchestration

# Contributing to AI Governance Platform

Thank you for your interest in contributing! Please follow these guidelines:

## How to Contribute
- Fork the repo and create a feature branch.
- Write clear, modular code with docstrings and type hints.
- Add/modify tests for your changes.
- Run `make lint` and `make test` before submitting a PR.
- Document new modules in their README.

## Code Style
- Python: Black, Ruff, Pydantic v2, FastAPI best practices
- Frontend: Prettier, ESLint, React

## Issues
- Use GitHub Issues for bugs, features, and questions.

---

Happy contributing!
